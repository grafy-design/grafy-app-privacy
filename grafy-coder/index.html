Grafy Coder 개인정보 처리방침

시행일: 2026-09-01 · 앱: Grafy Coder

Grafy Coder는 사용자가 소유하고 승인한 코딩 워크스테이션에 연결하는 컴패니언 앱입니다. 개인정보를 판매하거나 타사 광고 추적에 사용하지 않습니다.

1. 처리하는 정보

정보목적
앱·기기 버전, 기기 식별값, 연결 상태호환성, 보안, 세션 유지, 장애 대응
사용자가 입력한 워크스테이션 주소·별칭·연결 설정사용자가 승인한 로컬/원격 브리지 연결
터미널 세션 이름, 상태, 화면 미리보기, 사용자가 전송한 명령·텍스트세션 표시와 사용자가 요청한 원격 제어
사용자가 직접 실행한 스크린샷·음성 입력·피드백화면 증명, 음성 입력, 오류 해결
충돌·성능·오류 로그안정성과 보안 개선

2. 저장과 전송

연결 자격정보와 비밀값은 가능한 한 사용자 기기 또는 사용자가 관리하는 브리지에 보관합니다. 원격 기능을 사용할 때 필요한 정보는 암호화된 통신으로 해당 브리지에 전송됩니다. 앱 운영 로그는 필요한 최소 범위에서 최대 90일 보관할 수 있으며, 프로젝트·브리지 데이터는 사용자가 삭제하거나 연결을 제거할 때 삭제됩니다.

3. 제3자와 공유

Apple의 앱 배포·알림 서비스, 사용자가 선택한 인증 제공자, 호스팅·오류 진단 제공자가 기능 제공에 필요한 최소 정보를 처리할 수 있습니다. 법적 의무가 있는 경우를 제외하고 개인정보를 판매하지 않습니다.

4. 사용자 권리

앱에서 연결 설정과 저장 데이터를 삭제하거나 info@grafydesign.com으로 열람·삭제를 요청할 수 있습니다.

5. 보안 및 아동

전송 암호화, 최소권한, 단기 세션과 접근 통제를 사용합니다. 이 앱은 만 14세 미만 아동을 대상으로 하지 않습니다.
