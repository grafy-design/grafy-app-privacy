KNIL 나타 개인정보 처리방침

시행일: 2026-09-01 · 앱: KNIL 나타

KNIL 나타는 초대받은 사용자가 관심사와 하루의 기록을 데일리캐스트로 만들고 보관하는 앱입니다. 개인정보를 판매하거나 광고 추적에 사용하지 않습니다.

1. 처리하는 정보

정보목적
계정 식별값, 표시 이름, 앱·기기 버전로그인, 설정 동기화, 호환성
관심사·주제, 검색·프롬프트·대화 입력사용자가 요청한 데일리캐스트 생성과 검색

사용 기록, 충돌·성능·오류 로그기능 제공과 서비스 개선

2. 저장과 전송

사용자 콘텐츠는 계정에서 삭제하거나 탈퇴할 때까지 보관될 수 있습니다. 운영 로그는 최대 90일 보관할 수 있습니다. 생성 기능을 요청할 때 입력과 결과가 기능 제공에 필요한 처리 시스템으로 전송될 수 있습니다.

3. 제3자와 공유

Apple, 사용자가 선택한 인증 제공자, 콘텐츠 처리·호스팅·오류 진단 제공자가 기능 제공에 필요한 최소 정보를 처리할 수 있습니다. 개인정보와 사용자 콘텐츠를 판매하지 않습니다.
