GrafySync 개인정보 처리방침

시행일: 2026-09-01 · 앱: GrafySync

GrafySync는 사용자가 선택한 Obsidian 볼트·폴더를 지원되는 기기 사이에서 동기화합니다. 개인정보를 판매하거나 광고 추적에 사용하지 않습니다.

1. 처리하는 정보

정보목적
사용자가 선택한 파일 내용, 파일명, 폴더·볼트 이름, 수정시각과 해시파일 동기화, 변경 감지, 충돌 해결
기기 식별값·별칭, 앱/OS 버전, 동기화 상태기기 연결, 상태 표시, 호환성
동기화 오류·충돌·성능 로그장애 복구와 서비스 개선

2. 저장과 전송

파일은 사용자가 지정한 동기화 대상 사이에서 암호화된 통신으로 처리됩니다. 동기화 대상의 보관 기간은 사용자가 관리하며, 기기·폴더 연결을 제거하거나 삭제 요청을 하면 운영상 필요한 최소 로그를 제외한 관련 데이터를 삭제합니다. 운영 로그는 최대 90일 보관할 수 있습니다.

3. 제3자와 공유

Apple의 배포 서비스와 사용자가 선택한 동기화·호스팅 인프라가 기능 제공에 필요한 정보를 처리할 수 있습니다. 법적 의무가 있는 경우 외에는 개인정보를 판매하지 않습니다.

4. 사용자 권리

앱에서 동기화 폴더와 기기를 제거하거나 info@grafydesign.com으로 열람·삭제를 요청할 수 있습니다.

5. 보안 및 아동

전송 암호화와 최소권한 접근을 사용합니다. 이 앱은 만 14세 미만 아동을 대상으로 하지 않습니다.
